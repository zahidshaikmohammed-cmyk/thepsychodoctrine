# WEAPON 142 — THE LOCK IN CODE

When interest is clear, explain the next steps without presuming consent.
Say: “If you’d like to proceed, here’s how it works.”
Outline the timeline, paperwork, payment, and support.
Pause for questions and confirm that they want to continue.
Do not treat curiosity as a commitment.
A smooth process removes friction without removing choice.
Lock in the details only after the buyer agrees.
Momentum follows clarity.
