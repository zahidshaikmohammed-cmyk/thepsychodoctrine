# Weapon 105 — Decision Window Narrower

A decision window should be as narrow as the facts allow—and no narrower.

If a genuine deadline exists, state it. If more information is needed, identify what is missing and when it can be obtained.

Say: “What is the smallest useful next step we can decide today?”

Psycho narrows confusion, not freedom. He turns a large decision into a manageable sequence without pretending every step must happen immediately.

A clear window creates focus. A fake window creates distrust.
