# Weapon 111 — Deadline Without Deadline

Never invent a deadline to make an offer feel important.

When there is no fixed expiry, say so. Then agree on a useful follow-up date based on the client’s needs, not on a manufactured countdown.

Say: “There is no artificial deadline here. When would it be useful to revisit this?”

Psycho values momentum, but he values credibility more.

A chosen checkpoint creates structure without pretending time is running out.
